Har qanday Web sahifa ikkita qismdan tashkil topadi. Bular sarlavha qismi va asosiy qism. Sarlavha qismida Web sahifa haqidagi ma’lumot joylashadi, asosiy qismda esa Web sahifaning mazmuni bilan tasvirlanish qoidalari joylashadi. Sarlavha qismi quyidagi ochiluvchi   <head>  va yopiluvchi  </head> teglari orasida joylashadi. Asosiy qism esa  <body>  va </body>  teglari orasida joylashadi. Odatda sarlavha qismi oldidan qo`llanilayotgan HTML standartlari haqida ma’lumot yoziladi.

Har qanday Web sahifaning umumiy ko`rinishi quyidagicha bo`ladi:

<!Doctype html>
<html lang="en">
 <head>
  <title> Hujjat sarlavhasi </title>
 </head>
 <body>
   Asosiy qism
 </body>
</html>

№ Element Ta'rif
1 <!Doctype html> Veb sahifaning qaysi HTML versiyasida yozilganligi haqida brauzerga ma'lumot beradi. Hujjatning eng birinchi qatorida yoziladi.
2 <html> HTML hujjatining ildiz (yuqori darajadagi asosiy) elementini ifodalaydi. Web sahifadagi boshqa barcha elementlar ushbu teg ichida joylashadi.
3 <head> Hujjatning bosh qismi bo'lib, sarlavha, skriptlar, uslublar jadvallari (CSS) va meta ma'lumotlar kabi mashina tomonidan o'qiladigan ma'lumotlarni o'z ichiga oladi.
4 <title> Brauzerning sarlavha satrida yoki sahifa yorlig'ida (tab) ko'rsatiladigan hujjat sarlavhasini belgilaydi. Unda faqat matn bo'ladi.
5 <base> Hujjatdagi barcha nisbiy URL manzillar uchun asosiy URL manzilni belgilaydi. Bir hujjatda faqat bitta <base> elementi bo'lishi mumkin.
6 <meta> Boshqa meta elementlar (<base>, <link>, <script>, <style>, <title>) bilan ifodalab bo'lmaydigan metama'lumotlarni (kodirovka, tavsif, kalit so'zlar, viewport) belgilaydi.
7 <link> Joriy hujjat va tashqi resurs o'rtasidagi bog'liqlikni belgilaydi. Ko'pincha tashqi CSS fayllarini va sayt ikonkalarini (favicon) ulash uchun ishlatiladi.
8 <style> Hujjat yoki uning bir qismi uchun ichki CSS uslublar ma'lumotlarini o'z ichiga oladi.
9 <body> HTML hujjatining asosiy mazmunini (matnlar, rasmlar, havolalar, jadvallar, ro'yxatlar va boshqa ko'rinadigan elementlar) ifodalaydi. Bir hujjatda faqat bitta <body> elementi bo'ladi.
