Atributlar

Ushbu elementning atributlari global atributlarni o'z ichiga oladi.

autocomplete
Foydalanuvchi agentining avtomatik to'ldirish xususiyatiga ishora beruvchi satr. Qiymatlarning to'liq ro'yxati va avtomatik to'ldirishdan qanday foydalanish haqida tafsilotlar uchun HTML avtomatik to'ldirish atributiga qarang.
Element Display
<select autocomplete="on">Add to favorites </select>
autofocus
Ushbu Boolean atributi sahifa yuklanganda forma boshqaruvi kirish fokusga ega bo'lishi kerakligini belgilash imkonini beradi. Hujjatdagi faqat bitta forma elementi avtofokus atributiga ega bo'lishi mumkin.
disabled
Bu Boolean atributi foydalanuvchi boshqaruv elementi bilan o'zaro aloqa qila olmasligini bildiradi. Agar bu atribut ko'rsatilmagan bo'lsa, boshqaruv elementi o'z sozlamasini o'z ichiga olgan elementdan meros qilib oladi, masalan, <fieldset>; agar o'chirilgan atributlar to'plamiga ega bo'lgan o'z ichiga olgan element bo'lmasa, boshqaruv elementi yoqilgan bo'ladi.
