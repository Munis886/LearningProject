  • position CSS xususiyati

CSS position xususiyati elementning hujjatdagi joylashuv usulini belgilaydi. Elementning yakuniy joyi top, right, bottom, left yoki oqimga mos mantiqiy inset-* xususiyatlari bilan sozlanadi.

Sinab ko‘ring

Muharrirdagi position qiymati va ofsetlarni o‘zgartirib, elementlar joylashuvi qanday o‘zgarishini kuzating.

Sintaksis

position: static;
position: relative;
position: absolute;
position: fixed;
position: sticky;

position uchun beshta asosiy qiymat mavjud. Boshlang‘ich holatda barcha elementlar static qiymatidan foydalanadi.

static
Element odatiy hujjat oqimida joylashadi. top, right, bottom va left ofsetlari unga ta’sir qilmaydi.
relative
Element odatiy oqimdagi o‘rnini saqlaydi, so‘ng o‘zining dastlabki joyiga nisbatan siljiydi. Siljish uchun ajratilgan joy saqlanib qoladi.
absolute
Element odatiy oqimdan chiqariladi va eng yaqin joylashtirilgan ota elementga nisbatan joylashtiriladi. Bunday ota element bo‘lmasa, boshlang‘ich qamrov blokiga nisbatan joylashadi.
fixed
Element odatiy oqimdan chiqarilib, odatda brauzer oynasiga nisbatan joylashtiriladi. Sahifa aylantirilganda ham shu joyda qoladi.
sticky
Element avval odatiy oqimda joylashadi, belgilangan ofsetga yetgach esa eng yaqin aylantirish konteyneri chegarasida yopishib turadi. Bu holat uchun, masalan, top: 0 kabi auto bo‘lmagan qiymat kerak.

Ofsetlar va qatlamlar

Ofsetlar joylashtirilgan elementning chetini uning joylashuv kontekstiga nisbatan belgilaydi. position: relative, absolute, fixed va sticky elementlarda z-index ustma-ust chizilish tartibini boshqarishi mumkin. fixed va sticky har doim yangi stacking context hosil qiladi; relative va absolute esa z-index qiymati auto bo‘lmaganda hosil qiladi.
