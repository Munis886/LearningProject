5-Dars, if (Agar…)

Faraz qiling, siz saytingizda shunday funksiya qo´ymoqchisiz-ki, bunda user biror narsani bossa (yoki kiritsa) qandaydir hodisa yuz bersin, aks holda boshqa hodisa yuz bersin. Bunday ishlar if operatori bilan bajariladi. Tushunarli bo´lishi uchun: 

                    if (eshik ochiq) {
                        ichkariga kiramiz
                    }
                    else {
                        orqaga qaytamiz
                    }

Ya´ni: «Agar eshik ochiq bo´lsa ichkariga kiramiz, aks holda orqaga qaytamiz».

Bitta kichkina misol: saytimizga kirgan odamdan uning yoshini so´raymiz. Agar u 20 yoshdan kichik bo´lsa «Ukam siz hali yosh ekansiz», aks holda «Siz katta odam ekansiz» yozuvi chiqsin: 

                    <script type="text/javascript">
                    function tekshir() {
                        var a=son.value;
                        if (a<20) { alert("Ukam siz hali yosh ekansiz") }
                        else { alert("Siz katta odam ekansiz") }
                    }
                    </script>

                    Siz hozir necha yoshda:
                    <input type="text" size="10" name="son">
                    <input type="button" value="Tekshirish" onclick="tekshir()">

Siz hozir necha yoshda:

Endi confirm oynasini if bilan birlashtirib shunday programma tuzamiz: agar OK bosilsa sahifada «OK bosdingiz», aksincha Cancel bosilsa «Cancel bosdingiz» yozuvi chiqsin: 

                    <script type="text/javascript">
                    function savol() {
                        a=confirm("Salom qaleysiz")
                        if (a==true) { document.write("Siz OK ni bosdingiz") }
                        else { document.write("siz Canselni bosdingiz") }
                    }
                    </script>

                    <input type="button" value="bosing" onclick="savol()">

 

Yangi oyna ochish

Websaytdagi biror tugmani bosganda yangi oyna ochish mumkin. Buni open() buyru´i bilan bajariladi. Oyna hajmi va ko´rinishini ham belgilash mumkin: 

                    <script type="text/javascript">
                    function oyna() {
                        open("sahifa.html", "newWindow",
                          "width=300, height=200, toolbar=no, menubar=no");
                    }
                    </script>

                    <input type="button" value="Yangi oyna ochish" onclick="oyna()" />

Bunda: width — yangi oynaning eni (pixelda), height — balandligi, toolbar — tepadagi panel (yes/no), menubar — menu paneli (yes/no).

Eslatma: brauzerlar xavfsizlik maqsadida avtomatik ochilgan oynalarni bloklashi mumkin.

Oynani yopish uchun esa window.close() ishlatiladi:

                    <script type="text/javascript">
                    function chiqing(){
                        window.close()
                    }
                    </script>

                    <input type="button" value="Websaytdan chiqish" onclick="chiqing()">

Vaqtni ko´rsatish

JavaScript yordamida web-sahifada vaqtni ko´rsatish mumkin. Date() obʻekti undan quyidagi metodlar orqali maʼlumot olinadi:

MetodKo´rsatadi
getFullYear()Yil
getDate()Sana
getDay()Hafta kuni
getHours()Soat
getMinutes()Minut
getSeconds()Sekund
                    <script type="text/javascript">
                        vaqt = new Date();
                        soat = vaqt.getHours();
                        daqiqa = vaqt.getMinutes();
                        soniya = vaqt.getSeconds();
                        document.write("Hozir vaqt " + soat + ":" + daqiqa + ":" + soniya);
                    </script>

Bir xonali sonlarning oldiga nol qo´yishni ham o´rganamiz. Agar sekund (yoki minut) 10 dan kichik bo´lsa, oldiga 0 qo´shiladi: 

                    <script type="text/javascript">
                    function bajar() {
                        var vaqt=new Date();
                        var soat=vaqt.getHours();
                        var minut=vaqt.getMinutes();
                        var sekund=vaqt.getSeconds();
                        if (sekund<10) { natija=soat+ ":" +minut+ ":0" +sekund }
                        else { natija=soat+ ":" +minut+ ":" +sekund }
                    }
                    </script>

Biz yozgan kodlarda soat har gal sahifani qayta ochganda o´sha paytdagi vaqtni ko´rsatadi, lekin o´zi harakat qilmaydi. Ko´z o´ngimizda soat o´zgarib turishi uchun setTimeout(1000) buyru´i ishlatiladi — bunda 1000 millisekund = 1 sekund, ya´ni har 1 sekundda yangi vaqt ko´rsatiladi: 

                    <script type="text/javascript">
                    function soat() {
                        hozir = new Date();
                        hour = hozir.getHours();
                        minut = hozir.getMinutes();
                        sekund = hozir.getSeconds();
                        vaqtimiz = hour;
                        if (minut<10) { vaqtimiz += ":0"+minut } else { vaqtimiz += ":"+minut }
                        if (sekund<10) { vaqtimiz += ":0"+sekund } else { vaqtimiz += ":"+sekund }
                        document.forma1.vaqt.value=vaqtimiz;
                        setTimeout("soat()", 1000)
                    }
                    </script>

                    <script type="text/javascript">
                    function boshla() {
                        setTimeout( "alert('Mana men chiqdim')", 2000 );
                    }
                    </script>

Array — Massiv haqida

JavaScript tilidagi massiv bu obʻektdir. Bu xuddi tartibli qatorlarga o´xshaydi — uning yordamida bir qancha maʼlumotlarni saqlab, so´ng ularni boshqarish mumkin. Massiv quyidagicha yoziladi: 

                    <script type="text/javascript">
                    odam = new Array("Ahmad", "Akbar", "Muslim", "Baxtiyor", "Karim", "Islom")
                    document.write( odam[2] )
                    </script>

Bu kod sahifada Muslim yozuvini ko´rsatadi. Nimaga? Chunki JavaScript 0 dan boshlab sanaydi: [0]—Ahmad, [1]—Akbar, [2]—Muslim...

Massiv yordamida hafta kunlarini ham ko´rsatish mumkin. getDay() hafta kunining raqamini qaytaradi (0=Yakshanba, 1=Dushanba, ... 6=Shanba): 

                    <script type="text/javascript">
                    vaqt = new Date();
                    raqam = vaqt.getDay();
                    kunlar = new Array("Yakshanba", "Dushanba", "Seshanba",
                    "Chorshanba", "Payshanba", "Juma", "Shanba");
                    document.write(kunlar[raqam]);
                    </script>

Random — tasodif

Math.random() bizga tasodifan 0 va 1 oralig´idagi birorta sonni beradi. 10 gacha ixtiyoriy son chiqarmoqchi bo´lsak 10 ga ko´paytiramiz. Butun son olish uchun esa quyidagi metodlar ishlatiladi:

MetodVazifasi
Math.random()0 dan 1 gacha tasodifiy qiymat
Math.round()eng yaqin butun songa yaxlitlaydi
Math.floor()eng yaqin kichik butun sonni oladi
Math.ceil()eng yaqin katta butun sonni oladi
                    <script>
                        document.write( Math.round(Math.random()*10) );
                    </script>

Eslatma: floor ishlatilganda hech qachon 10 chiqmaydi, faqat 0 dan 9 gacha son chiqadi, chunki floor eng yaqin kichik sonni ko´rsatadi.

                    <script type="text/javascript">
                    maqol = new Array(6);
